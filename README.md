# Adam - نظام آدم

مشروع Flutter أولي عملي لتطبيق مبيعات ومخزون وحسابات يعمل محلياً على Android.

## التشغيل على FlutLab
1. ارفع ملف ZIP إلى FlutLab أو ارفع المشروع من GitHub.
2. افتح المشروع.
3. نفّذ Pub Get.
4. نفّذ Build Project.
5. اختر Android target لبناء APK.

يدعم المشروع:
- واجهة عربية RTL
- هوية داكنة فاخرة
- لوحة تحكم
- أصناف ومخزون
- عملاء
- موردون
- مصروفات
- شاشة مبيعات
- شاشة مشتريات
- تقارير وإعدادات
- قاعدة بيانات SQLite محلية
- USD كأساس
- تجهيز لسعر صرف الليرة السورية

## ملاحظة
تم تضمين مجلد Android داخل النسخة، مع AndroidManifest وMainActivity وGradle configuration، لتكون البنية أقرب لمشروع Flutter كامل قابل للبناء على FlutLab.
